# Expense Tracker

A simple command-line application built in Python to manage daily expenses.

## Features
- Add expenses with amount, category, and note.
- View all recorded expenses.
- Calculate total spending.
- Data saved permanently using CSV file handling.

## Technologies Used
- Python
- CSV Module (File Handling)

## How to Run
1. Install Python on your system.
2. Run the command: `python expense_tracker.py`
